Chapter 13

Structures: one box, many labels

A roof truss is not one number. Each timber has a length, an angle, and a type (top chord, bottom chord, web). Keep those in three separate arrays and you spend all day praying the indexes line up. A struct puts all three in one labelled box called Member, so a single variable carries the whole timber.

A struct is a type you invent. It bundles a few named values, its members, under one name. An int holds one whole number; a Member you design holds a length, an angle, and a type together. You define the shape once, then declare as many variables of that shape as you like. Reach inside with the dot: m.length is the length member of the variable m.

Here is the whole thing: define Member, declare one variable, fill its members, print them.

#include <iostream>
#include <string>
using namespace std;

struct Member {
    double length;
    double angle;
    string type;
};

int main() {
    Member m;
    m.length = 2.4;
    m.angle = 30.0;
    m.type = "top chord";

    cout << m.type << ": " << m.length << "m at "
         << m.angle << " degrees" << endl;
    return 0;
}

You can also fill every member at birth with a brace list, in the order they are declared. This is initialization: the values go in as the variable is created, so nothing is ever left as garbage.

#include <iostream>
#include <string>
using namespace std;

struct Member {
    double length;
    double angle;
    string type;
};

int main() {
    Member m = {2.4, 30.0, "top chord"};   // order matches the struct
    cout << m.type << " is " << m.length << "m" << endl;
    return 0;
}

Build it: one timber of the truss

Save the listing above as member.cpp, then compile and run: g++ -std=c++17 member.cpp -o member && ./member. That single Member is the first timber. Next we cut a whole truss out of them.

A truss is not one timber, it is many. For a row of the same struct, use an array of structs: Member truss[3] is three Member boxes in a line. Pick a box by index, then a member by dot: truss[0].length. A for loop walks every timber the same way it walks any array.

#include <iostream>
#include <string>
using namespace std;

struct Member {
    double length;
    double angle;
    string type;
};

int main() {
    Member truss[3] = {
        {2.4, 30.0, "top chord"},
        {2.4, 30.0, "top chord"},
        {4.0,  0.0, "bottom chord"}
    };

    double total = 0.0;
    for (int i = 0; i < 3; i++) {
        cout << truss[i].type << ": " << truss[i].length << "m" << endl;
        total += truss[i].length;
    }
    cout << "Timber to order: " << total << "m" << endl;
    return 0;
}

The same shape fits anything with a few named facts. A library catalogues books, so the past paper uses Book with a title, an author, and a year. Different theme, identical machinery.

#include <iostream>
#include <string>
using namespace std;

struct Book {
    string title;
    string author;
    int year;
};

int main() {
    Book b = {"Things Fall Apart", "Chinua Achebe", 1958};
    cout << b.title << " by " << b.author
         << " (" << b.year << ")" << endl;
    return 0;
}

Challenge: spot the bug

A student wants the second dish in the menu. The struct is struct Dish { string name; double price; }; and the array is Dish menu[3]. They write cout << menu.name; and the compiler refuses. What is wrong, and what is the fix?

Answer: menu is the whole array, not one dish, so it has no .name. Pick a box first, then a member: menu[1].name (index 1 is the second dish, since counting starts at 0).

Q1. Define a structure named Spot to hold a tourist spot's name (text), region (text), and entry fee (a whole number of shillings). Then declare and initialize one variable of it for "Victoria Falls" in the "Livingstone" region with a fee of 30.

Model answer

Define the shape, then declare a variable and initialize it with a brace list in member order.

#include <iostream>
#include <string>
using namespace std;

struct Spot {
    string name;
    string region;
    int fee;
};

int main() {
    Spot s = {"Victoria Falls", "Livingstone", 30};
    cout << s.name << " (" << s.region << "): "
         << s.fee << " shillings" << endl;
    return 0;
}

The members are named in the struct, filled in the same order by the brace list, and read back with the dot.

Q2. Using a Book structure (title, author, year), build an array of 3 books, then write a loop that prints only the books published before the year 2000.

Model answer

Declare the array with an initializer list, then loop with an if that tests the year member of each element.

#include <iostream>
#include <string>
using namespace std;

struct Book {
    string title;
    string author;
    int year;
};

int main() {
    Book shelf[3] = {
        {"Things Fall Apart", "Chinua Achebe", 1958},
        {"Half of a Yellow Sun", "Chimamanda Adichie", 2006},
        {"Petals of Blood", "Ngugi wa Thiong'o", 1977}
    };

    for (int i = 0; i < 3; i++) {
        if (shelf[i].year < 2000) {
            cout << shelf[i].title << " (" << shelf[i].year << ")" << endl;
        }
    }
    return 0;
}

Index picks the book (shelf[i]), the dot picks the member (shelf[i].year). The loop applies the same test to every box.

Q3. Explain the difference between an array and a structure, and say when you would combine them. Use a recipe example.

Model answer

The two group data in opposite ways:

Array, many of one type. All elements are the same type, reached by a number index. double amount[5] holds five quantities and nothing else; amount[2] is the third.

Structure, one of several types. Members can be different types, reached by name. struct Ingredient { string name; double amount; string unit; }; holds a text name, a number, and a text unit together, reached as ing.name and ing.amount.

Combine them when you have many records that each carry several named facts: a recipe is an array of structs, Ingredient recipe[10], so each slot is one full ingredient and the loop walks the whole list. That is the exact pattern behind the roof truss: Member truss[3].
