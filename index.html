Your 8-week study pack

Everything runs in your browser. No internet, no install.

How to use this

  1. Click a week below. It opens as one page in your browser.
  2. Each week has 6 days. Do one day a sitting: read the idea, look at the diagram and code, do the "Build it" step, then answer the quiz. The quiz tells you right or wrong instantly and explains why.
  3. Use the buttons at the bottom: Prev / Next to move between days, Mark day done ✓ when you finish one.
  4. Theme button (top-right) switches light/dark if your eyes want it.
  5. Go in order, Week 0 → Week 7. Week 7 ends with a timed mock exam.

Want to run the C code yourself? (optional)

Each lesson already shows the code and what it prints, so you can learn without running anything. To actually run it, the code files live in the Weeks/onramp and Weeks/week1…week7 folders (files ending .c). Two ways:

  1. No install (needs internet): open onlinegdb.com/online_c_compiler, paste a .c file's contents, press Run.
  2. On your PC: install a C compiler once (Windows: search "install gcc mingw"; Mac: run xcode-select --install), then gcc filename.c -o out and run out.

The mock-exam notes are also in Weeks/The-C-On-Ramp-Notes.pdf.
