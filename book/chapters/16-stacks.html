Chapter 16

The Stack

You cut trusses all morning and the offcuts pile up beside the saw. The piece you drop on last is the one sitting on top, so it is the one you grab first. Nobody digs to the bottom of the pile for a short. That pile has a name in code: a stack. Last one in is the first one out. Learn the pile and you have learned undo buttons, back buttons, and the way the computer itself remembers where it was.

A stack is a list you may only touch at one end, the top. You add to the top (push), you take from the top (pop), and you may peek at the top without taking it (peek). You cannot reach into the middle. This one rule is called LIFO: Last In, First Out. The last thing you pushed is the first thing you pop.

Four moves cover everything a stack does:

MoveWhat it does
push(x)put x on the top
pop()remove the top and hand it back
peek()look at the top, leave it there
isEmpty()true when nothing is on the pile

A stack backed by an array

The simplest stack is a fixed array plus one integer, top, that marks the index of the topmost item. Start it at -1 to mean "empty". To push you step top up by one, then write. To pop you read, then step top down by one. The offcut rack, in code:

#include <iostream>
#include <string>

const int MAX = 100;

struct OffcutStack {
    std::string item[MAX];
    int top = -1;

    bool isEmpty() { return top == -1; }
    bool isFull()  { return top == MAX - 1; }

    void push(std::string cut) {
        if (isFull()) { std::cout << "rack full\n"; return; }
        item[++top] = cut;          // step up, then write
    }

    std::string pop() {
        if (isEmpty()) { std::cout << "rack empty\n"; return ""; }
        return item[top--];         // read, then step down
    }

    std::string peek() {
        if (isEmpty()) return "";
        return item[top];
    }
};

int main() {
    OffcutStack rack;
    rack.push("300mm pine");
    rack.push("450mm pine");
    rack.push("80mm pine");

    std::cout << "top of rack: " << rack.peek() << "\n";
    std::cout << "grab: " << rack.pop() << "\n";
    std::cout << "grab: " << rack.pop() << "\n";
    std::cout << "top of rack: " << rack.peek() << "\n";
    return 0;
}

The array way is fast and tiny, but it has a ceiling: MAX slots and no more. Push past the top slot and the rack is full. When you cannot guess the size ahead of time, reach for the second design.

A stack backed by a linked list

Think of a sink of dirty dishes after a big meal. Each dish points down at the one under it. The top pointer holds the plate you can see. To push, make a new node whose next is the old top, then move top to it. To pop, hand back the top and move top down to next. No fixed size: the pile grows until memory runs out.

#include <iostream>
#include <string>

struct Node {
    std::string dish;
    Node* next;
};

struct PlateStack {
    Node* top = nullptr;

    bool isEmpty() { return top == nullptr; }

    void push(std::string dish) {
        top = new Node{dish, top};   // new node points at the old top
    }

    std::string pop() {
        if (isEmpty()) return "";
        Node* old = top;
        std::string dish = old->dish;
        top = old->next;             // slide down one
        delete old;                  // give the memory back
        return dish;
    }
};

int main() {
    PlateStack sink;
    sink.push("bowl");
    sink.push("mug");
    sink.push("plate");

    while (!sink.isEmpty()) {
        std::cout << "wash: " << sink.pop() << "\n";
    }
    std::cout << "sink empty? " << (sink.isEmpty() ? "yes" : "no") << "\n";
    return 0;
}

Build it: truss offcut tracker

Real site step. You are framing a roof and every truss cut leaves a short. Save the array program as rack.cpp, then each time you drop an offcut on the pile, push its length; each time you use one, pop it. The rack always hands you the most recent cut first, which is the one still fresh in your hand.

Compile and run: g++ -std=c++17 rack.cpp -o rack && ./rack

Reverse a string with a stack

Here is the trick that shows off LIFO. Push every letter of a word onto a stack, then pop them all back off. Because the last letter in is the first letter out, the word comes back reversed for free. The C++ standard library ships a ready-made stack, std::stack, so you rarely hand-roll one in real code.

#include <iostream>
#include <string>
#include <stack>

int main() {
    std::string word = "TABLE";
    std::stack<char> s;

    for (char c : word) s.push(c);      // T, A, B, L, E go on

    std::string reversed;
    while (!s.empty()) {
        reversed += s.top();            // E comes off first
        s.pop();
    }

    std::cout << word << " reversed is " << reversed << "\n";
    return 0;
}

Challenge: predict the output

You visit three tourist spots and drop a ticket stub on a spike as you leave each one. What does this print?

#include <iostream>
#include <stack>

int main() {
    std::stack<int> spike;
    spike.push(2);      // Victoria Falls
    spike.push(4);      // Hwange
    spike.push(6);      // Great Zimbabwe
    std::cout << spike.top();
    spike.pop();
    std::cout << spike.top();
    spike.pop();
    std::cout << spike.top() << "\n";
    return 0;
}

Answer: 642. The last stub pushed (6) is the first one seen, so the spike reads back in reverse of the order you visited.

Exam practice

Q1. Define a stack and state the principle it follows. Give one everyday example.

Model answer

A stack is a linear data structure where items are added and removed at one end only, called the top. It follows the LIFO principle, Last In First Out: the most recently added item is the first one removed. Its core operations are push (add to the top), pop (remove from the top), peek (read the top without removing), and isEmpty (test whether it holds anything). Everyday example: a pile of offcuts beside a saw, where you grab the piece you dropped on last.

Q2. Implement a stack of integers using an array. Show the push and pop operations in a complete program.

Model answer

#include <iostream>

const int MAX = 100;

struct Stack {
    int item[MAX];
    int top = -1;

    bool isEmpty() { return top == -1; }
    bool isFull()  { return top == MAX - 1; }

    void push(int x) {
        if (isFull()) { std::cout << "overflow\n"; return; }
        item[++top] = x;
    }

    int pop() {
        if (isEmpty()) { std::cout << "underflow\n"; return -1; }
        return item[top--];
    }
};

int main() {
    Stack s;
    s.push(10);
    s.push(20);
    s.push(30);
    std::cout << s.pop() << "\n";   // 30
    std::cout << s.pop() << "\n";   // 20
    return 0;
}

Note the two guards. isFull stops a push past the last slot (overflow); isEmpty stops a pop on nothing (underflow). Without them the program reads or writes outside the array.

Q3. Implement a stack using a linked list. Show push, pop, and isEmpty.

Model answer

#include <iostream>

struct Node {
    int data;
    Node* next;
};

struct Stack {
    Node* top = nullptr;

    bool isEmpty() { return top == nullptr; }

    void push(int x) {
        top = new Node{x, top};      // new node points at old top
    }

    int pop() {
        if (isEmpty()) { std::cout << "underflow\n"; return -1; }
        Node* old = top;
        int x = old->data;
        top = old->next;
        delete old;
        return x;
    }
};

int main() {
    Stack s;
    s.push(5);
    s.push(9);
    std::cout << s.pop() << "\n";        // 9
    std::cout << (s.isEmpty() ? "empty" : "not empty") << "\n";
    return 0;
}

The linked-list stack has no fixed limit, so there is no isFull: it grows until memory runs out. Each pop calls delete so freed nodes do not leak.

Q4. Write a complete program that reverses a string using a stack.

Model answer

#include <iostream>
#include <string>
#include <stack>

int main() {
    std::string name = "SADZA";
    std::stack<char> s;

    for (char c : name) s.push(c);   // push every letter

    std::string result;
    while (!s.empty()) {
        result += s.top();           // pop pulls them back reversed
        s.pop();
    }

    std::cout << result << "\n";       // AZDAS
    return 0;
}

Why it works: pushing loads the letters in reading order, so the last letter sits on top. Popping empties the stack from the top down, which hands the letters back in the opposite order. LIFO does the reversing; you write no reversing logic of your own.
