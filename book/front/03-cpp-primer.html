Front matter

A from-zero C++ primer

You cannot plan a roof with a language you cannot speak. This chapter is the whole of C++ you need to start: enough to read every listing in the book and write your own. It assumes nothing. If you have never compiled a program, start here.

Compile and run

A C++ program is plain text in a file, usually ending .cpp. The computer cannot run that text directly. A compiler (the program g++) translates it into a runnable file first. That two-step, compile then run, is the whole loop.

#include <iostream>

int main() {
    std::cout << "Hello, site." << std::endl;
    return 0;
}

Build it

Save that as hello.cpp, then run these two commands:

g++ -std=c++17 hello.cpp -o hello
./hello

The first makes a file called hello; the second runs it. You should see Hello, site.

Read the program line by line. #include <iostream> pulls in the input/output tools. int main() is where every program starts. The two braces { } hold the body. Every statement ends in a semicolon. return 0; tells the system the program finished cleanly.

Printing with cout

std::cout is the standard output, your screen. The << arrow feeds things into it, left to right. Chain as many as you like. std::endl ends the line.

#include <iostream>

int main() {
    std::cout << "Boards needed: " << 12 << std::endl;
    return 0;
}

A variable is a named box holding a value. In C++ you say the box's type when you make it, so the compiler knows how big it is and what fits.

#include <iostream>

int main() {
    int trusses = 3;
    double span = 4.8;          // metres
    std::cout << trusses << " trusses over " << span << "m" << std::endl;
    return 0;

Reading input with cin

std::cin is the standard input, the keyboard. The >> arrow points the other way: it pulls a typed value into a variable.

#include <iostream>

int main() {
    int trusses;
    std::cout << "How many trusses? ";
    std::cin >> trusses;
    std::cout << "Cutting " << trusses << " frames." << std::endl;
    return 0;
}

bool and if

A bool is a yes/no value: true or false. An if runs a block only when its condition is true; the optional else runs when it is false. Compare with == (equal), != (not equal), <, >, <=, >=.

#include <iostream>

int main() {
    int span = 5;
    bool needsSupport = span > 4;   // true when span over 4m
    if (needsSupport) {
        std::cout << "Add a centre post." << std::endl;
    } else {
        std::cout << "A plain triangle will hold." << std::endl;
    }
    return 0;
}

Loops

A loop repeats a block. A for loop counts: start, keep-going condition, step. A while loop repeats as long as its condition stays true. The loop below cuts one truss at a time until the roof is full.

#include <iostream>

int main() {
    int total = 4;
    for (int i = 1; i <= total; i = i + 1) {
        std::cout << "Truss " << i << " raised." << std::endl;
    }
    return 0;
}

Challenge

How many lines does the loop above print, and what is the last one? (Answer: four lines; the last is Truss 4 raised.)

Functions

A function is a named block you can call by name. It can take parameters (inputs) and return a value. Writing the calculation once and calling it keeps the site numbers in one place.

#include <iostream>

// boards needed for one truss, given its span in metres
int boardsFor(double span) {
    if (span > 4) {
        return 5;   // triangle plus centre post plus braces
    }
    return 3;       // plain triangle
}

int main() {
    std::cout << "Wide truss: " << boardsFor(5.0) << " boards" << std::endl;
    std::cout << "Narrow truss: " << boardsFor(3.0) << " boards" << std::endl;
    return 0;
}

std::string

std::string holds text. Include <string> to use it. Join strings with +, and ask a string its length with .size().

#include <iostream>
#include <string>

int main() {
    std::string timber = "pine";
    std::string label = "Cut from " + timber;
    std::cout << label << " (" << label.size() << " chars)" << std::endl;
    return 0;
}

struct: group related values

A struct bundles several values into one named type. One truss has a span and a count of boards; a struct lets you carry both together as a single thing. Reach inside with a dot.

#include <iostream>
#include <string>

struct Truss {
    std::string name;
    double span;
    int boards;
};

int main() {
    Truss t;
    t.name = "gable";
    t.span = 4.8;
    t.boards = 5;
    std::cout << t.name << ": " << t.boards << " boards" << std::endl;
    return 0;
}

new and delete: memory by hand

Sometimes you do not know how many trusses you need until the program runs. new asks the system for memory while running and hands back its address (a pointer, written *). Reach through a pointer with ->. When you are done you must give the memory back with delete, or it leaks. The data structures later in this book are built on exactly this.

#include <iostream>
#include <string>

struct Truss {
    std::string name;
    int boards;
};

int main() {
    Truss* t = new Truss;      // ask for memory at run time
    t->name = "hip";           // reach through the pointer
    t->boards = 6;
    std::cout << t->name << ": " << t->boards << " boards" << std::endl;
    delete t;                  // give the memory back
    return 0;
}

Challenge: spot the bug

A colleague writes new Truss in a loop that runs a thousand times but never calls delete. The program slowly eats all the memory on the machine. What is the fix? (Answer: every new needs a matching delete. Free each truss when you are done with it.)

Q. Explain the difference between std::cout and std::cin, and name the operator used with each.

Model answer

std::cout is the standard output stream; it writes to the screen and uses the insertion operator <<, which feeds values out to it. std::cin is the standard input stream; it reads what the user types and uses the extraction operator >>, which pulls a value into a variable. The arrows point in the direction the data flows: out of the program with <<, into a variable with >>.
