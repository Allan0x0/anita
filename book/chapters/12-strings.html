Chapter 12

Characters and Strings

Look around a build site and text is everywhere. Every truss member carries a label ("top chord", "king post"). Every spec string names a grade ("C24 timber"). Every recipe in the site canteen has a name ("Jollof Rice"). A program that cannot hold and handle text cannot handle any of this. That is what characters and strings are for.

Two tools, one job. A char holds exactly one character: a single letter, digit, or symbol. You write its value in single quotes, like 'A'. A std::string holds a run of characters of any length, from empty to a whole sentence. You write its value in double quotes, like "top chord". Rule of thumb: one character means char; a word, a name, or a label means std::string. To use std::string you add #include <string> at the top.

Here is one char and one std::string side by side, so the two kinds of quote are clear.

#include <iostream>
#include <string>

int main() {
    char grade = 'A';                  // one character, single quotes
    std::string member = "top chord";  // many characters, double quotes

    std::cout << "Grade:  " << grade << "\n";
    std::cout << "Member: " << member << "\n";
    return 0;
}

Reading and printing. Printing is easy: send the string to std::cout. Reading a whole line (spaces and all) uses std::getline(std::cin, name). Plain std::cin >> name would stop at the first space, so "Cape Coast" would come in as just "Cape". For labels and place names, reach for getline.

#include <iostream>
#include <string>

int main() {
    std::string label;
    std::cout << "Enter the member label: ";
    std::getline(std::cin, label);
    std::cout << "You labelled it: " << label << "\n";
    return 0;
}

The common operations. Five you will use constantly, shown on a recipe name. .length() counts the characters. + joins (concatenates) two strings. [i] reaches one character by index. .substr(start, count) cuts out a piece. == compares two strings for an exact match.

#include <iostream>
#include <string>

int main() {
    std::string recipe = "Jollof Rice";

    std::cout << "Length: " << recipe.length() << "\n";   // 11

    std::string full = recipe + " and Chicken";           // concatenate
    std::cout << "Full:   " << full << "\n";

    std::cout << "First:  " << recipe[0] << "\n";           // J
    std::cout << "Piece:  " << recipe.substr(0, 6) << "\n"; // Jollof

    if (recipe == "Jollof Rice") {
        std::cout << "Names match.\n";
    }
    return 0;
}

Char arrays: the older way. Before std::string, C++ (inherited from C) stored text in a char array ending in a hidden null terminator '\0' that marks the end. You still meet them, so know the shape: char spot[] = "Cape Coast"; makes an array sized to fit the text plus that terminator. Index it like any array. Prefer std::string in your own code (it grows, compares, and concatenates for you), but recognise the array form when you see it.

#include <iostream>

int main() {
    char spot[] = "Cape Coast";  // char array, auto sized (adds '\0')
    std::cout << "Spot:  " << spot << "\n";
    std::cout << "First: " << spot[0] << "\n";  // C

    spot[0] = 'K';               // change one character in place
    std::cout << "Now:   " << spot << "\n";     // Kape Coast
    return 0;
}

Build it

On the truss job, print a tidy label for every member. Save the recipe listing as ops.cpp, then:

g++ -std=c++17 ops.cpp -o ops && ./ops

Truss step: replace "Jollof Rice" with a member name such as "king post", add " (C24)" with + to stamp the timber grade onto the label, and rebuild. That joined string is exactly what you would paint or print on the physical member.

Challenge: predict the output

Read it, do not run it. What three things print, and on what one line?

#include <iostream>
#include <string>

int main() {
    std::string truss = "howe";
    std::cout << truss[0] << truss[3] << truss.length();
    return 0;
}

Answer: he4 on one line. truss[0] is 'h', truss[3] is 'e', and "howe" has 4 characters, so length() is 4. There is no newline in the code, so it is all one line.

Q1. Define a char and a std::string, and explain the difference between them. Give one example of each.

Model answer

A char is a data type that holds exactly one character (a letter, digit, or symbol), written in single quotes, for example 'A'. A std::string is a type that holds a sequence of characters of any length, written in double quotes, for example "top chord". The difference: a char is a single fixed character, while a std::string is a run of many characters that can grow, shrink, be joined, and be compared as a whole. In short, use char for one character and std::string for words or labels. (Using std::string needs #include <string>.)

Q2. Write a complete C++ program that stores the recipe name "Waakye" in a string, then prints its length, its first character, the first three characters, and the name joined with the word " Special".

Model answer

Use .length(), index [0], .substr(0, 3), and + for the join.

#include <iostream>
#include <string>

int main() {
    std::string recipe = "Waakye";

    std::cout << "Length: " << recipe.length() << "\n";     // 6
    std::cout << "First:  " << recipe[0] << "\n";             // W
    std::cout << "First3: " << recipe.substr(0, 3) << "\n";   // Waa
    std::cout << "Joined: " << recipe + " Special" << "\n";   // Waakye Special
    return 0;
}

Q3. An array holds five tourist spots in no particular order. Write a complete C++ program that sorts them into alphabetical order using Selection Sort, then prints them.

Model answer

Selection Sort walks the array. For each position i, it scans the rest to find the smallest remaining string, then swaps that smallest into position i. Strings compare with <, which C++ evaluates alphabetically (dictionary order), so no special comparison code is needed.

#include <iostream>
#include <string>

int main() {
    std::string spots[5] = {"Kumasi", "Accra", "Tamale", "Cape Coast", "Bolga"};
    int n = 5;

    // Selection Sort: pick the smallest, put it at the front, repeat.
    for (int i = 0; i < n - 1; i++) {
        int min = i;
        for (int j = i + 1; j < n; j++) {
            if (spots[j] < spots[min]) {   // alphabetical compare
                min = j;
            }
        }
        std::string temp = spots[min];     // swap i and min
        spots[min] = spots[i];
        spots[i] = temp;
    }

    for (int i = 0; i < n; i++) {
        std::cout << spots[i] << "\n";
    }
    return 0;
}

Output, in order: Accra, Bolga, Cape Coast, Kumasi, Tamale.

Q4. Spot the bug. A student wants to store a single grade letter but the program will not compile. What is wrong, and how do you fix it?

char grade = "A";

Model answer

The value "A" uses double quotes, which make a string (a run of characters), but grade is a char, which holds one character. The types do not match. Fix it with single quotes: char grade = 'A';. If a full word were really needed instead, the other fix is to change the type: std::string grade = "A";.
