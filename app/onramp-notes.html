BITH132 · Data Structures & Algorithms · Week 0

The C On-Ramp

Six short days. Just enough C to walk into Unit 1 standing up, learned by building a roof truss.

How this week works

One day per day. Read the idea, type the code on your laptop, compile and run it, then answer the quick check. Miss a day? The week has slack; just pick up where you left off. The phone app has the same six days with instant-feedback quizzes; this PDF is for reading offline.

Setup once per laptop (see the install guide): VS Code + gcc. Compile & run any file: gcc file.c -o out then ./out.

Day 1 · Setup & first run

Print a truss, run a program

A program is a list of instructions the computer runs top to bottom. Today you write three lines of shapes and watch a roof appear.

printf means "print, formatted": it puts text on the screen. gcc is the compiler: it turns the C you typed into a program the machine can run.

The code: day1_hello_truss.c

\n = "new line". Each printf ends one line of the drawing.

Build it

Compile: gcc day1_hello_truss.c -o day1  then  run: ./day1. You should see the little roof, then My first truss!. That's the loop you repeat every day: write → compile → run.

Check yourself

1. What does gcc do?

  1. Runs a website
  2. Turns your C code into a program you can run
  3. Deletes your files

b. gcc is the compiler: it translates C into a runnable program.

2. What does printf do?

  1. Prints text to the screen
  2. Prints paper on a printer
  3. Reads the keyboard

a. printf writes text to the screen. The f is for "formatted".

3. In gcc day1.c -o day1, what is -o day1?

  1. An error
  2. The name of the finished program
  3. The C version

b. -o names the output program. Here it's called day1.

Day 2 · Variables & types

Boxes that hold your numbers

A variable is a labelled box that holds one value. The type says what kind of value fits.

Three types carry almost everything: int for whole numbers (member count), float for decimals (span, pitch), and char for a single character (timber grade).

The code: day2_variables.c

The slots %d %f %c fill from your variables: %d = int, %.1f = float to 1 decimal, %c = char.

Build it

gcc day2_variables.c -o day2 then ./day2. Then change the span to 8.5 and the grade to 'A', run again, watch the output change.

Check yourself

1. Which type holds a decimal like 6.0?

  1. int
  2. float
  3. char

b. float holds decimals; int is whole numbers only.

2. %d in printf fills with a…

  1. Whole number (int)
  2. Decimal
  3. Single letter

a. %d = int, %f = float, %c = char.

3. char grade = 'B';, single quotes hold…

  1. A whole sentence
  2. Exactly one character
  3. A number

b. Single quotes = one char. Words (many chars) use double quotes.

Day 3 · Input

Let the user type the span

So far the numbers were baked in. scanf reads what the user types and drops it into a variable.

Notice the & before the variable. It means "the address of": you're telling scanf where the box lives so it can fill it. Keep it in mind: in Unit 4 the & becomes pointers, and it'll already feel familiar.

The code: day3_input.c

Build it

gcc day3_input.c -o day3 then ./day3. Type a number, press Enter. Try a whole number and a decimal, both come back with two decimal places.

Check yourself

1. What does scanf do?

  1. Prints to screen
  2. Reads what the user types
  3. Scans for viruses

b. scanf reads keyboard input into a variable.

2. Why the & in scanf("%f", &span)?

  1. It multiplies
  2. It tells scanf WHERE to store the value
  3. It's a typo

b. & = "address of". It hands scanf the box's location. This idea grows into pointers in Unit 4.

3. %f reads a…

  1. Decimal number
  2. Word
  3. Whole number only

a. %f matches a float (decimal).

Day 4 · Decisions

Ask a question, branch on the answer

A program earns its keep when it decides. if runs a block only when a test is true; else catches the rest.

Rule of thumb on site: a simple truss handles a moderate span. Too wide needs an engineer; too small, a single beam. Let the program say which.

The code: day4_decisions.c

Build it

Run it three times: try 15, 2, then 6. Each should hit a different message. If one doesn't, re-read the tests; that's debugging.

Check yourself

1. If span is 15, which message prints?

  1. Too wide - needs an engineer
  2. Standard truss territory
  3. Very small

a. 15 > 12, so the first if is true and wins.

2. else if runs when…

  1. Always
  2. The if above was false AND its own test is true
  3. Never

b. Each branch is only reached if the ones above were false.

3. If span is 6, the output is…

  1. Too wide
  2. Very small
  3. Standard truss territory. Good.

c. 6 is not >12 and not <3, so the else catches it.

Day 5 · Loops

Do the same job many times

A roof has many identical rafters. A loop repeats a block instead of you copying it. The for loop counts: start, keep-going test, step.

Peek ahead: lengths[0] is an array, a row of boxes. That's the whole of Unit 1, and you're already using it.

The code: day5_loops.c

i++ means "add 1 to i". The first loop counts 1,2,3,4,5.

Build it

gcc day5_loops.c -o day5 then ./day5. Change rafters to 8, and add a 4th length; remember to change [3] to [4] and the loop's 3 to 4.

Check yourself

1. for (i=1; i<=5; i++) runs how many times?

  1. 4
  2. 5
  3. 6

b. i goes 1,2,3,4,5: five passes.

2. Across the loop, total = total + lengths[i]…

  1. Adds every length together
  2. Prints each length
  3. Deletes lengths

a. It accumulates the running total, the sum of all members.

3. lengths[0] is…

  1. The first length (2.5)
  2. The last length
  3. The total

a. Arrays count from 0, so [0] is the first box. Remember that for Unit 1.

Day 6 · Functions & words

Name a job, reuse it

A function is a named chunk of work. You give it inputs (arguments), it hands back a result. Write it once, call it anywhere.

A word like a member label is a string, stored in a char array. That's Unit 2, previewed. After today you've touched a little of the next six weeks already.

The code: day6_functions.c

%s prints a string. The height math is deliberately rough; from Unit 1 on you'll make it real.

Build it

Run it, then call truss_height a second time with a different span and print that too. One function, used twice: that's the whole point.

Check yourself

1. A function lets you…

  1. Name a chunk of work and reuse it
  2. Slow the program down
  3. Only run once

a. Write the logic once, call it as many times as you like.

2. In truss_height(6.0, 30.0), 6.0 and 30.0 are…

  1. Errors
  2. The inputs (arguments)
  3. Line numbers

b. They're the arguments: the values you feed the function.

3. char label[10] holds…

  1. One number
  2. A short word / string
  3. A whole book

b. A char array holds a string, up to 9 letters plus a hidden end-marker.
