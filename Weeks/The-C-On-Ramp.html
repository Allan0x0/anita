Day 1 · Setup & first run

Print a truss, run a program

A program is a list of instructions the computer runs top to bottom. Today you write three lines of shapes and watch a roof appear.

printf means "print, formatted": it puts text on the screen. gcc is the compiler: it turns the C you typed into a program the machine can actually run.

The code

\n = "new line". Every printf ends one line of the drawing.

Build it

Open the file in VS Code, then in the terminal run: gcc day1_hello_truss.c -o day1  then  ./day1 You should see the little roof, then My first truss!. That's the whole loop you'll repeat every day: write → compile → run.

Day 2 · Variables & types

Boxes that hold your numbers

A variable is a labelled box that holds one value. The type says what kind of value fits in the box.

Three types carry almost everything: int for whole numbers (member count), float for decimals (span in metres, pitch angle), and char for a single character (timber grade).

The code

The %d %f %c are slots: %d fills with an int, %f with a float (%.1f = 1 decimal place), %c with a char.

Build it

Compile and run: gcc day2_variables.c -o day2 then ./day2. Then change the span to 8.5 and the grade to 'A', run again, and watch the output change.

Day 3 · Input

Let the user type the span

So far the numbers were baked in. scanf reads what the user types at the keyboard and drops it into a variable.

Notice the & before the variable name. It means "the address of": you're telling scanf where the box lives so it can fill it. Keep that & in mind: in Unit 4 it becomes pointers, and it'll already feel familiar.

The code

Build it

Run it: gcc day3_input.c -o day3 then ./day3. Type a number, press Enter. Try a whole number and a decimal, both should come back with two decimal places.

Day 5 · Loops

Do the same job many times

A roof has many identical rafters. A loop repeats a block instead of you copying it. The for loop counts: start, keep-going test, step.

Peek ahead: lengths[0] is an array, a row of boxes. That's the whole of Unit 1, and you're already using it.

The code

i++ means "add 1 to i". The loop counts 1,2,3,4,5.

Build it

Run it: gcc day5_loops.c -o day5 then ./day5. Change rafters to 8 and add a fourth length to the array (remember to change [3] to [4] and the loop's 3 to 4).

Day 6 · Functions & words

Name a job, reuse it

A function is a named chunk of work. You give it inputs (arguments), it hands back a result. Write it once, call it anywhere.

A word like a member label is a string, stored in a char array. That's Unit 2, previewed. After today you've touched a little of the next six weeks already.

The code

%s prints a string. The height math is deliberately rough; Unit 1 onward you'll make it real.

Build it
