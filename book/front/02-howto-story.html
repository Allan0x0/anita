How to use this book

This is a field guide, not a textbook. Every chapter is built the same way, so once you know the parts you can walk straight to what you need.

The parts of a chapter

PartWhat it is
HookWhy you should care. One paragraph, on the timber strip, before any theory.
IdeaThe plain explanation. No jargon that has not been defined first.
DiagramA drawing of the thing. Read it before the code.
CodeA real C++ listing you can compile with g++ -std=c++17. Type it, do not skim it.
Build itThe exact command to compile and run, plus the step it adds to the project.
ChallengePredict the output, or spot the bug, before you run it. This is where the learning happens.
ExamA question in the style of the paper, with a worked model answer.

Build it

You need one thing installed: a C++ compiler. On the lab machines that is g++. Test it now: g++ --version. If you see a version number, you are ready.

The running project: raise a roof

Every idea in this book earns its place by helping raise one roof. You are the site programmer for a small building firm. The carpenters cut and nail; your job is to keep the numbers straight so the roof goes up square, on time, and without wasted timber.

A roof is a row of trusses: triangular timber frames, spaced evenly, that carry the load from the walls to the ridge. Building the software to plan that roof turns out to need every data structure on the syllabus:
